DESIGN REQUIREMENTS
- Three separate auditoriums/screens.
- Screen 1 is IMAX; Screens 2 and 3 are standard.
- Black/charcoal and warm gold palette; no purple.
- No 4DX.
- No side balconies.
- Each auditorium has its own screen, seating area and seat selection.

IMPORTANT FOR VS CODE
These PNGs are visual reference assets, not a ready-made 3D model or Java application.
Use them as references when implementing the 3D auditorium and booking interface.
Keep the original seat maps as the source for row/seat arrangement; do not infer exact
seat counts or dimensions from the decorative interior renders.
